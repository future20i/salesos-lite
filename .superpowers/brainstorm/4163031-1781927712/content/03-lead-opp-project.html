销售的三层结构：线索 → 商机 → 项目

之前的管道设计把这些全摊平成了任务卡片。真正的销售工作需要分层视图。

👤
线索 Lead
"有人对这个感兴趣"
不确定能否成交
→
🎯
商机 Opportunity
"这个单子有预算有时限"
有金额、有把握、在推进
→
🏗️
项目 Project
"合同签了，开始交付"
有里程碑、有交付物
⚠ 之前的错误：把「张总要报价」「李总要技术方案」「王总签合同」全部摊平成管道里的卡片，没有体现它们之间的父子关系——一个商机下有多个跟进项，多个跟进项推动一个商机往前走。

正确的结构：商机是容器，跟进项是子任务

商机状态流转（替代之前的四列任务管道）

🔍 线索验证
"这人值不值得跟？"
AI 从对话中识别意向
→
📋 需求确认
"他要什么？预算多少？"
跟进项：需求调研 + 报价
→
💰 报价/谈判
"价格能不能谈拢？"
跟进项：报价/方案/谈判
→
📝 合同
"走法务、签章"
跟进项：合同 + 审批
→
✅ 成交
→ 转为交付项目
每个阶段有自己的一组跟进项模板。所有跟进项完成 → 自动推进阶段。
流失 和 搁置 是两个独立的终态，不是阶段。

线索 → 商机的转化判断

不是每个线索都值得开商机。AI 辅助判断，人做决定。

🔍 AI 自动评分
预算明确 ✓ "大概400-500万"
决策人清楚 ✓ 张总·技术总监
时间紧迫 △ "下季度前"
竞品在比 ✗ 有进口品牌对比
综合评分 72/100 · 建议转化
转化 → 商机
创建商机卡片，分配跟进模板，入管道
保持 → 线索
还不成熟，继续培育。AI 定期提醒跟进
放弃 → 归档
明确不感兴趣或预算不匹配
