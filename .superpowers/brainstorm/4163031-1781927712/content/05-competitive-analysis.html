🔑 市场缺口：所有人都在做「记录」，没人在做「决策」

现有CRM做的事
客户信息存储
销售管道可视化
邮件追踪 + 提醒
报表和仪表盘
AI辅助写邮件
基础自动化工作流
→ "发生了什么"的系统
SalesOS 要做的事
客户沉默 → AI诊断原因（竞品？流程？忘了？）
诊断后 → AI建议策略（降价？发案例？找决策人？）
建议后 → AI起草消息（个性化的跟进文案）
起草后 → 人审核（把关+修改）
审核后 → 发出（跨平台一站式）
发出后 → AI监测回复（客户回了自动唤醒）
→ "该做什么"的决策引擎

📊 总结：为什么所有现有系统都不够

1 OKKI是唯一接近的竞品——但它被阿里锁定，AI是功能叠加不是架构原生。它的AI做的是「辅助回复」，不是「诊断-建议-起草-审核-执行」的完整决策链路。
2 Pipedrive/HubSpot/Zoho/SF都是通用CRM，外贸场景需要大量定制。它们面向的是「已有明确销售流程」的企业，不是「需要AI帮你建立流程」的外贸小团队。
3 没有人做语音快速捕获——出差/电话/展会场景的信息录入是一块完全空白的市场。这是入口级的差异化。
→ SalesOS 的竞争定位：外贸AI决策引擎——不是「又一个CRM」，而是「最先发现该做什么、帮你起草、等你审核、替你发出、监测回复」的AI副驾驶。OKKI是功能对标，但我们在AI原生架构和决策链路上有机会超越。
